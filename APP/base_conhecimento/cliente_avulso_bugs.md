# Cliente tem contrato mas está aparecendo que é Cliente Avulso, o que está ocorrendo?

**Existem duas possibilidades:**

1. O cliente tem um contrato com data de início no futuro. Verifique a data de início. Caso esteja no futuro, então o cliente ainda será avulso até chegar a data de início do contrato.
2. O cliente provavelmente tem um contrato mas já está encerrado. Verifique a data de encerramento. Caso a data esteja no passado então o cliente está sendo exibido corretamente como avulso.

   Caso contrário são exibidos todos os planos ativos.
